# GUI handoff notes

Approved visual direction:
- modern dark graphite UI
- restrained gold accent
- no retro-LCD imitation
- no 1990s dense librarian aesthetic

Approved interaction direction:
- single central workspace with switch: Bank A / Bank D / Multi
- visibility switch: 16 / 32 / 64 / 128 slots
- avoid paging through 8 pages per bank
- multi-selection via Ctrl and Shift
- lasso selection
- bank-to-bank movement via Copy/Cut/Paste
- Explorer drag-and-drop is required in production
- conventional Windows shortcuts are required
- context actions for selected patches:
  - Export as KA1
  - Convert to SysEx
  - Send to .IMG
- whole-bank actions:
  - Convert active A/D bank to SysEx
  - Send active A/D bank to .IMG
- Multi should follow the same interaction model where possible

This prototype is deliberately non-functional with respect to K5000 binary formats.
